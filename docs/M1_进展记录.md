## 2. 环境实测发现（决定 OCR 参数，回写 matcher 文档注）

- **问题**：rapidocr 3.9.2（本机 venv）默认 Det `limit_type=min` + 层级
  `limit_side_len`(736/960/1500/2000)：300×90 小条带会被放大到 **736×2464**，
  单次 OCR 稳态 0.9–6.8s；1280² 以上 det 输入出现 ~15× 非线性的耗时跳变。
- **修复**：引擎 OCR 引擎初始化强制 `Det.limit_type=max, limit_side_len=960`
  （模块级单例）。实测（i9-13900H，物理中文渲染 + 真实 ERP 资产）：
  - 合成 300×90 找“库存查询”：**稳态 ~90–140ms/次**（识别正确）
  - 真实 ERP 页面菜单条带 260×70：**~81ms/次**（识别“库存查询”正确）
  - 整页 1288×988 全页 OCR 仍 ~10s → 引擎默认**不做整页 OCR**，
    部件/存在性搜索一律“小区域条带”（见 §4 设计注）
- 模板匹配（cv2 5.0，CPU）：300×90 模板全屏搜索稳态 **36ms**；合成页 1.15× 缩放偏移定位 **145ms**。
- M0 结论复用：OCR rec 慢 → “条带优先 + 命中即停”策略落地 locator（框相关行内收紧带，
  替代固定 (300,100)/(650,260) 高条带——实测高条带把页面其他行/框线的 det 盒成批卷进，
  600×194 单次可达 4–6s）。
- **性能风险登记（2026-09-09 实测并定案/登记）**：
  1. OCR 漂移（已定案修复）：默认(-1)/1 线程在 ~15 次连续推理后漂移到 0.4~4.9s/次；
     **intra_op_num_threads=4 + inter=1 连续 20+ 次稳定 37–51ms/条带** → 引擎默认采用；
  2. ORT 推理后紧邻的 cv2 匹配偶发短暂变慢（数百 ms，数拍恢复）→ 引擎固定
     cv2 单线程 + 大模板“金字塔粗选 top-2 全分辨率精修”（页面定位实测 ~0.6–1.1s）；
     部件模板按已锁定页面缩放**单档匹配**（文字仍是主信号）；
  3. 验收口径：单步部件定位 ≤500ms 以模板路径中位数为准；OCR 条带路径按实测波动登记，
     “文本索引缓存”列为 M1 中段优化项。

## 3. 引擎设计定稿点（波次2 及联调引用的契约）

1. **页面定位次序**（清单 §3）：整窗模板 0.8~1.25× → 静态锚；同屏连续步骤用
   “上一矩形快速复验”（reused 命中 ≈ 省一次全屏多尺度扫描），失配自动回落全量搜索。
2. **页内约束**：所有部件搜索在页面裁剪内进行；任何越界候选盒直接丢弃并记
   `*_out_of_page`（构造“页面外诱饵”负例测试通过）。
3. **exists 语义（条件/循环/预期结果共用）**：①UI 树(无提供者跳过) + ②相似度，
   **③页内坐标不参与“看到”**（坐标还在 ≠ 内容还在）——波次1 定稿并测试锁定。
4. **until 循环跨页语义**：条件目标所属页面尚未出现（如登录后跳转中）→ 视为
   “还没看到”继续循环（与 §4.1 示例“直到看到 首页 {等待2s}”一致）；
   达上限（默认 1000，可配）→ `loop_limit` 失败记录，不终止脚本。
5. **点击安全闸引擎化**（M0 实证：校验不过不点）：点击前取点击点周边
   ±210×120 新帧做文字/模板复验；不过闸 = 过程性错误（不发送点击）。
6. **L1/L2 边界**：过程性错误（page/widget/guard）→ 校验钩子（若配）→ L1 自动重试
   N 次 → 白话提示（继续/跳过/停止）；结果性失败（预期结果未出现）→ `on_fail`
   四策略（retry 耗尽后转白话提示），**绝不触发校验入口**（清单 §3 状态机）。
7. **校验钩子契约（E5 波次2 实现）**：`calibrator(CalibRequest) -> CalibResult`；
   `CalibRequest{reason(first_run|page_not_found|widget_not_found|click_guard_failed),
   step, target, page_spec, page_rect, loc_rows, ctx}`；
   `CalibResult{ok, updated, page_spec?, note?}`；`updated+page_spec` → 写回并
   立即重试该步（不消耗 L1 重试）；首次执行校验由 `RunConfig.calibrate_first_run` 开启。
   引擎侧已完成触发/写回/报告（`report.calib`），测试覆盖（mock 校验器）。
8. **HumanIO 契约（Electron IPC 落点）**：`notify(message)`（提示我步骤）、
   `prompt_not_found`（L1，继续/跳过/停止）、`prompt_outcome_fail`（L2 失败，
   继续/停止）；无交互界面时默认“停止”（无人值守安全）。
9. 定位日志行 = `{ts, step_id, event(locate_page|locate_widget|exists_check|outcome_check|
   click_guard|procedural_fail), method(page_tpl|anchor|ocr_text|tpl|page_coord|ai|none|
   ocr_patch|tpl_fallback|guard_off|no_patch), confidence, rect, screen_meta, detail}`；
   点击安全闸每次判定都记日志（含通过）；`tail(step_id,n)` 供校验调阅。
10. **页面命中同源确认（波次1 实测定案）**：整窗模板 CCOEFF 命中后须通过像素同源复验
    （`pixel_sim(thr=16, 240×150) ≥0.82`）才算页面确认——大面积白底/低纹理 UI 会让
    跨页模板假阳性（实测 0.72+ 阈值下异页命中率可达 100%）；改版页同源不过 → 自然走
    锚定位/校验入口，定位日志 detail.page_tpl.sim 记录分值。
11. **C 层挂死护栏（2026-09-09 实测：ORT det 与 cv2 matchTemplate 在本机存在概率性
    冻结 >400s，1.25/1.29 ORT、4.13/5.0 cv2 均复现，numpy 正常——疑似底层并行运行时
    与大小核调度病态）**：OCR 与模板匹配都在守护线程执行（超时 8s/10s）；连续超时
    3 次 → 熔断冷却 30s（期间该路径快速失败，自动退化为下一级定位信号），冷却结束
    OCR 自动重建引擎自愈（`ocr_reset()/cv_reset()` 可手动重置）；测试运行器每个测试
    前重置计数，防跨测试污染。

## 4. 波次1 显式不做的部分（登记，避免范围蔓延）

- UI 树（①级）真实提供者 → 波次2 接 live 窗口（locator 已留 `uia_provider` 槽）；
- 校验模式 E5 / AI 适配层 E7（含授权知情提示）→ 波次2；
- 真实窗口回归资产迁移（fixtures html + targets/*.png → `.sgscript.json`）→ 波次2；
- 全页 OCR 与“文本索引缓存” → 维持关闭/后续（M1 中段按 ≤500ms 实测再定）；
- IPC 契约（JSON-RPC 方法清单/UI 弹窗）→ UI 里程碑联调时立项；
- 手工简写脚本（target 无 page）仅 validate 级通过；运行期页面解析要求至少一步带 page
  （与录制产物一致）；条件页缺失走“否则”并如实记录。
