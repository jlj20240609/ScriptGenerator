# M1 运行时识别流程（供审查）

> 版本：2026-09-10（对应提交 `793fa84`）｜权威实现：`engine/locator.py`（定位）、
> `engine/matcher.py`（匹配原语）、`engine/executor.py`（执行与失败处理）、
> `engine/calibrator.py`（自动校准）。
> 本文按"运行时真实发生顺序"描述，所有阈值都取自代码常量。

## 0. 一次动作步骤的全景

```
抓屏(整屏 BGR)
  └─ A 页面定位 ──► 页面矩形(page_rect) + 页面缩放(page_scale)   ← 失败 = page_not_found
       └─ B 部件定位（在页面裁剪内做，绝不越页）                  ← 失败 = widget_not_found
            └─ C 点击安全闸（只对 点一下/点两下/输入文字）        ← 失败 = click_guard_failed
                 └─ D 执行动作（点 / 双击 / 点后输入文字）
                      └─ E L2 预期结果（如果配了"做完后应该看到"）  ← 失败 = 结果性失败

任一过程性失败（A/B/C）→ F 失败阶梯：自动校准(1次) → L1 重试(3次) → 白话弹窗(继续/跳过/停止)
E 失败 → 走"没看到就…"策略（再试一次 / 提示我 / 停止 / 跳过），**不触发自动校准**
```

一句话取舍：**页面先锁死，部件只在页面内找**（越页的候选一律丢弃）；**证据不足时宁可报"没找到"，也不猜着点**。

## A. 页面定位（`locator.locate_page`）

按顺序尝试，命中即返回：

| 步 | 判据 | 阈值/细节 | 命中标记 |
|---|---|---|---|
| A0 | **上一帧同矩形快速复验**：把整窗模板缩放到上一帧矩形大小，在该位置附近再匹配一次 | 单尺度；命中位置偏移 ≤ **6px**；像素同源 ≥ **0.82**；且命中区**中心 80%** 的灰度标准差 ≥ **6**（一片纯色不算命中） | `page_tpl` + `reused=true`（多步连续运行时省掉全屏多尺度扫描） |
| A1 | **整窗模板多尺度**：0.80/0.85/0.90/0.95/1.00/1.05/1.10/1.15/1.20/1.25 共 10 档；大模板走"降采样粗选 top-2 + 原分辨率精修" | 相关系数 ≥ **0.72**；同源确认**三档**：≥0.82 稳 / **0.80~0.82 且模板分数 ≥0.85 → 勉强可用**（采纳 + 标 `soft` + 置信度 ×0.9）/ 更低丢弃；同样要求标准差 ≥6 | `page_tpl`（`soft=true` 时定位日志标 `soft`） |
| A2 | **静态锚**：页面里预先存的静态小图（顶栏/logo 等），逐锚匹配后按几何还原页面原点 | 锚 ≥ **0.75**；还原矩形必须在屏幕内（越界丢弃） | `anchor`（记录 `scale`） |
| — | 都不中 | 返回失败，`detail` 里带各锚分数，供校准器使用 | → `page_not_found` |

**为什么要"像素同源确认"**：整窗模板用相关系数在大片白底/低纹理页面上会有假阳性（跨页也能到 0.72+）。同源确认把"看起来像但不是同一页"的挡掉；**纹理下限**再挡一层"页面白屏/加载中"的情况（实测纯白页的同源分数也有 0.883、CCOEFF 对零方差区域会给假高分，只有中心标准差能识别出来）。

## B. 部件定位（`locator.locate_widget`，在页面裁剪内进行）

### B0 准备
- 页面裁剪 `page_live_bgr` = 整屏按 `page_rect` 裁下；后续所有坐标都是**页内坐标**，返回时再加页面原点。
- `exists` 语义（"如果看到 / 一直重复直到看到 / 做完后应该看到"共用）：**只认强证据**（①UIA 与 ②a/②b），**③页内坐标与 ②c 环带都不参与**——"坐标还在 ≠ 内容还在"。

### B1 ①级：UI 树（仅当运行时有 UIA 提供者且目标有文字）
- 按 `text` 查 UI 树；命中盒必须**在页面内**、且**不整页**（≥70% 页面面积的大容器直接弃用）。
- 同名多实例：取**离录点预测中心最近**的；距离 > **60px** 视为坐标系不可靠 → **本级弃用**（M0 实测 Edge DOM 坐标偏差形态）。
- 无提供者/无文字 → 跳过本级（**不算失败**）。

### B2 ②a 文字条带（默认主信号，`match=auto/text_first`）
- 从目标文字取"短词 needle"，在**条带**里 OCR 找词，文本相似度 ≥ **0.75**。
- 条带尺寸策略（避免把整页 det 盒卷进来导致慢）：
  - 有录点：先"框紧邻带"（行内收紧）→ 再"横向放宽带"；
  - 无录点：页心大带 + **页高 78% 处点**（贴近页底的提示文字也能找到）。
- 小字（区域高 < 70px）自动 2× 放大再试一次。
- **同一路径上会收集全部命中候选**（`matcher.find_text_all_ocr`），而不是"第一个命中就完"——
  同页常出现相同文字（列表同名列、重复的"保存"按钮、两个一样的占位提示）。
- 候选挑选（用户审查后新增）：
  1. **邻居文字对得上的优先**（见 B4.5 相对锚点）；
  2. 其次**离录点预测中心近的**（切比雪夫距离）；
  3. 再其次相似度高的。
- 距录点超过 `far_limit = max(2×模板宽, 2×模板高, 160px)` 的候选被降级为
  **"远候选"**：排在整块模板/环带**之后**（`detail.l2_ocr_far_only` 会标出来），
  只在没有更强证据时才用它——即"位置相近才采纳"。`exists` 语义下远候选不参与。

### B3 ②b 整块模板（兜底 / `match=image_first` 主信号）
- 单档（按页面实际缩放）；相关系数 ≥ **0.70**。
- **搜索窗 = 录点附近**：以录点预测中心为心，±(0.6×模板宽, 1.2×模板高)（各不小于 80/48px）。
- **不做全页搜索**：同页常有外观相同的控件（两个一样的输入框/按钮），全页搜会错配到另一个身上（实测：录下面那个却定位到上面那个，分数 1.000 却是错位置）。确实重排了 → 交给 ③ + 安全闸 + 校准。

### B4 ②c 环带模板（"认边框不认内容"，仅当 ②b 失配时启用）
- 掩码只取模板**四边**（环宽 = 短边 22%，夹 3~10px），**中心内容区完全不参与**。
- 相似度 = `1 - RMSE/64`（每像素每通道均方根误差；整片底色差 46 灰阶 → 0.30，会被拒），阈值 ≥ **0.60**。
- 用途：输入框被填入数据后，占位提示没了、整块图案也变了，但**边框与底色没变** → 还能稳定定位。（`exists` 语义下不认它。）

### B4.5 相对锚点（邻居文字，用户审查后新增）

- **录制时**（双截图第二步）自动把目标**四周一圈**（左右 ±180px、上下 ±60px，排除目标框内部）
  的静态文字一起记进 `target.nearby = [{text, rect_in_page, offset:[dx,dy]}]`，最多 4 条，
  `offset` 相对目标中心（随目标一起移动）。UI 日志会回显"顺手记住旁边 N 处文字"。
- **运行时**：对每个候选，按 `offset` 推算邻居应该在的位置，在那里做一次小窗 OCR
  （相似度 ≥ **0.72**，最多验 2 条）；命中 → 该候选 `nearby_ok=true`。
- 作用：同页多个相同文字时**用邻居消歧**（并优先于"距离近"）。没有 `nearby` 的旧脚本不受影响。
- 取舍：邻居是"辅助判据"，不是硬门槛——邻居一条都没验到时返回 `None`，不参与排序。

### B4.6 融合与偏好
- `match=auto/text_first`：按 **近文字 → 整块模板 → 环带 → 远文字** 依次取第一个可用结果；
  `match=image_first`：**整块模板 → 环带 → 近文字 → 远文字**。
- 双信号同点（两路中心相距 ≤ **30px**）→ 置信度融合加分。
- 选中的那一路决定 `method`（`ocr_text` / `tpl` / `tpl_ring`）与 `level=2`；
  `detail.l2_ocr` 会记下候选总数、近/远各几个、选中项的距离与邻居结果，便于事后审查。
- `exists`（如果看到）只认 **近文字 / 整块模板 / UIA**：环带与远文字都不参与。

### B6 ③级：页内坐标兜底（几何）
- 仅在 `exists=false`（即"要操作它"）时参与：用录点矩形 × 页面缩放算出屏幕盒。
- 任何候选盒越出页面 → 丢弃并记 `*_out_of_page`。

## C. 点击安全闸（`executor._click_guard`，仅 点一下/点两下/输入文字）

定位成功**不等于**可以点。点击前在**部件框 + 边距**范围内（`pad_x = min(160, 40%宽+40)`、
`pad_y = min(60, 60%高+24)`，上限 720×320；没有框时回落到点击点 ±210×60）抓一小块，依次复验
（用户审查后改：原来固定用"点击点 ±210×60"，控件比这块大时只验到一部分）：

| 序 | 方式 | 阈值 | 说明 |
|---|---|---|---|
| C1 | 目标文字 OCR | 相似度 ≥ 0.75 | 最直接：这一小块里还有那行字 |
| C2 | 整块模板 | ≥ 0.55（尺度 1.0/0.75） | 图案还在 |
| C3 | 环带模板 | ≥ 0.60 | 只比外圈：输入框被填过内容时靠它放行 |

三道都不过 → `click_guard_failed` → 走失败阶梯（**不发送点击**）。这就是 M0 定下的"校验不过不点"。

---

## D. 执行动作

- `点一下/点两下`：把鼠标移到部件中心单击/双击。
- `输入文字`：先点击部件中心聚焦，再用 **SendInput(KEYEVENTF_UNICODE) 直发字符**——绕开中文输入法（普通按键会被 IME 拦成拼音组合，且候选框浮窗会挡住页面导致整窗模板掉到 0，真人实测）。

---

## E. L2 预期结果（"做完后应该看到"）

- 动作完成后轮询"是否看到那个东西"（`exists` 语义），超时 **3s**、间隔 **0.5s**。
- 看到 → 本步 ✓；一直没看到 → 结果性失败 → 按 `on_fail.strategy` 处理：
  `retry`（再试一次）/ `notify`（提示我）/ `stop`（停止）/ `skip`（跳过）。
- **结果性失败不触发自动校准**（内容没出现 ≠ 定位不可靠）。

---

## F. 失败阶梯（过程性失败 A/B/C）

```
1) 自动校准（E5）——每步只试一次
   · 目标：用语义/AI 在页面内重新圈出部件，或整窗重采集页面，写回脚本（targets_rev +1）
   · 成功(updated) → 不消耗 L1 次数，立即重试该步
   · 失败 → 保留旧值，继续往下
2) L1 自动重试 **2 次**（间隔 1s）——用户意见：3 次偏多，改 2 次
3) 白话弹窗：没找到"xx"，请确认屏幕上有没有这个东西 →
   **继续 / 用记下来的位置点一次 / 跳过 / 停止**
   · "继续" = 手动处理完后重新从第 2 步计（可再来 2 次）
   · "用记下来的位置点一次"（用户要求新增的半自动降级）= 忽略识别结果，直接按框选时
     记下的位置点一次；**跳过点击安全闸**，只发一次；没记下位置时如实说明并重新让用户选
```
- 页面整体找不到时，弹窗文案换成"没找到这个界面（操作页面），请确认窗口是否已打开"。
- 循环：`重复 N 次` / `一直重复，直到看到`（上限 1000 次）/ `一直重复`（靠停止按钮）。

## G. 定位日志（JSONL，`LocLogger`）

每步一行，字段：`ts / step_id / event / method / confidence / rect / screen_meta / extra`。
`event` 取值：`locate_page`、`locate_widget`、`click_guard`、`exists_check`、
`procedural_fail`、`outcome_check`。
校准器会把该步最近 30 行日志一起拿到（`log.tail(step_id, 30)`），用于判断"是位置变了还是内容变了"。

## H. 判据与阈值总表（一页纸）

| 环节 | 判据 | 阈值 | 不通过时 |
|---|---|---|---|
| A0 复用复验 | 相关系数 + 偏移 + 同源 | 0.72 / ≤6px / ≥0.82 | 落到 A1 |
| A1 整窗模板 | 多尺度相关系数 + 同源 | ≥0.72 / ≥0.82 | 落到 A2 |
| A2 静态锚 | 锚相关系数 + 几何还原 | ≥0.75 | `page_not_found` |
| B1 UI 树 | 名字命中 + 盒在页内 + 非整页 + 距录点 ≤60px | — | 落 ② |
| B2 文字 | 条带 OCR 文本相似度；候选按 邻居 → 距离 → 分数 排序 | ≥0.75；邻居 ≥0.72；远 > `max(2w,2h,160)` | 落 ②b |
| B3 整块模板 | 录点附近窗口内相关系数 | ≥0.70 | 落 ②c |
| B4 环带模板 | 四边掩码 MSE→RMSE 相似度 | ≥0.60 | 落 ③ |
| B4.5 邻居文字 | 按 offset 推算位置的小窗 OCR | ≥0.72（最多验 2 条） | 该候选不加分 |
| B6 页内坐标 | 几何（仅非 exists） | — | `widget_not_found` |
| C1/C2/C3 安全闸 | 文字 / 整块 / 环带 | 0.75 / 0.55 / 0.60 | `click_guard_failed` |
| E L2 | exists（轮询 3s/0.5s） | — | 走 `on_fail` |
| F L1 | 自动重试 | **2 次** × 间隔 1s | 白话弹窗（4 选项） |

性能口径：单步部件定位 ≤ **500ms** 以**模板路径中位数**为准（真窗实测 232–427ms）；OCR 条带路径波动已登记（稳态 ~40–150ms/条带，冷启动/熔断另计）。

## I. 已知取舍与风险

**已按你的意见落实（2026-09-10，第二批）**：

| 你的意见 | 落实 |
|---|---|
| "宁可失败也不误点"的偏向认可 | 写入设计原则（本文件开头），后续改动都按这个偏向取舍 |
| 同源确认 0.82 偏严 → 折中 | 加"勉强可用"档：**0.80~0.82 且模板分数 ≥0.85 → 采纳 + `soft` 标记 + 置信度 ×0.9**。线定在 **0.80 而不是更低**是实测定的：同页改动后同源仍 0.93+（0.82 并不严），而异页能到 0.772、纯白页 0.884 —— 压到 0.72 会放行异页 |
| 安全闸改成"以部件框 + 边距"取 patch | 已改（`pad_x/pad_y` 按框尺寸自适应，上限 720×320）；定位日志里的 patch 矩形同步真实值 |
| 默认记录"候选盒 top-3 及分数" | `detail.l2_ocr.top3` 与定位日志 `extra.top3` 默认写入：`[盒, 分数, 距录点距离, 邻居是否对上]` × 3 |

**顺带发现并修掉一个既有漏洞**（审查的副产品）：整屏**纯白/空白页**能骗过前两道门 ——
CCOEFF 对零方差区域给假高分，而同源分数也有 0.883（>0.82）。现在加了**纹理下限**：
命中区中心 80% 的灰度标准差 < 6 直接判不命中（页面崩溃/加载中不再被当成目标页）。

**已定**（用户 2026-09-10）：锚候选分数**不默认落盘**，维持"只在页面定位失败时写进 `detail`"——
避免定位日志膨胀；真要排查页面失配，看那一条 `locate_page` 的 `detail.anchors` 即可。
