# M4 计划 — 脚本导出 Skill/Tools + 自然语言生成

开工：2026-09-11　官方依据：分析文档 §M4（第 1090 行）、§8 全章、§7.4 #3/#4；过程文档 §3 M4 门禁

## 1. 官方范围（原文摘录）

> ### M4 — 脚本导出 Skill/Tools + 自然语言生成
> - **脚本 → Skill + Tools 导出器（第 8 章）**：导出时拼装（模式 A 先行）+ 目标 Agent 目录自动检测与写入（8.6）。
> - "帮我做一个自动登录" → 自动生成步骤。
> - 双导出出口：**图片脚本导出（①）与 AI 代码脚本转译（②，读截图生成可读源码）**，导出向导由用户自选（8.9）。
> - 脚本编辑：拖拽排序、复制粘贴步骤。

**DoD（过程文档 §3）**：导出产物在真实 Agent 目录加载运行通过；AI 代码脚本转译产物通过
引用完整性校验；单向导出标注正确。

**边界（沿用 M0~M3 的既定结论，本里程碑不放松）**：坐标一律走本地三级定位；
云端 AI 只做语义判定与转译，**绝不作为运行时坐标源**；导出物不是自包含代码——
识别/输入仍在**本机引擎**执行，Agent 侧只拿到"调用编排 + 部件数据"（§8.2 ⚠️）。

## 2. 工作包

### WP1 导出器核心（`engine/exporter.py`）——纯逻辑，不碰界面与网络

按 §8.8 的转化流程实现，模式 A（导出时拼装）先行：

| 步骤 | 做什么 | 依据 |
| --- | --- | --- |
| 解析 | 脚本 JSON → 原子操作序列（含条件/循环嵌套） | §8.8 |
| 拼装 | 每个步骤 → 一次函数调用，按顺序串成调用链 | §8.8 |
| 参数化 | 字面量（输入文本／等待秒数／循环次数）→ skill 入参 | §8.4 |
| 数据 | 步骤引用的部件信号 → `WIDGETS` 注册表（全局去重合并） | §8.7 |
| 修饰 | 原子函数加 `@tool`（tool schema）；调用链加 `@skill` | §8.1 |
| 校验 | 引用完整性（用到的部件/工具必须存在）+ 产物可编译 | DoD |

产物（§8.7 默认通用格式）：`skills/<name>.py`、`tools/screen.py`（含 WIDGETS）、
`tools/registry.py`。

### WP2 目标 Agent 目录适配与自动写入（`engine/agent_dir.py`）

§8.6 四步：只读扫描（识别 skills/ tools/ 入口与**已有工具清单**）→ 按已注册工具名对齐并
**求差集**（已有则复用、不覆盖）→ 干跑预览（新增/覆盖/跳过 + 差异）→ 冲突检测（覆盖/跳过/改名）→
写入 → 提示"刷新/重启 Agent"。识别不出框架时退回通用目录导出并提示手动放置。

### WP3 导出向导（界面）

出口选择（图片脚本／代码脚本／两者）→ Agent 目录（可保存多个配置、可干跑预览）→
确认写入 → 结果与刷新提示。**白话文案**，不出现 RPA/术语。

### WP4 AI 代码脚本转译（双出口 ②）

云端多模态读**全部页面/部件截图** + 步骤序列 → 可读 Python 源码（每步带注释 + 参数接口）。
规则（§8.9）：上传截图前显式授权（复用 M3 的 AiGate）；产物标注"由 vX 脚本生成，
修改脚本后请重新导出"（**单向导出**）；引用不存在的部件要在导出前拦截；
无 UIA 元素可译时退化为坐标/视觉语义代码或建议改用出口 ①。

### WP5 一句话生成脚本

自然语言（"帮我做一个自动登录"）→ 步骤。与 WP4 共用同一条 AI 转译管线（§8.9）。
生成结果是**可编辑的步骤骨架**：动作 + 目标语义描述（写进 `target.semantic`），
运行时由**本地**定位按语义找部件——这样"一句话"也不越界（云端不产出坐标）。

### WP6 脚本编辑：拖拽排序 + 复制粘贴步骤

### WP7 收口

案例库回归（导出产物真跑）+ DoD 三项验收数据 + `docs/M4_收口记录.md`。

## 4. 风险与对策

| 风险 | 后果 | 对策 |
| --- | --- | --- |
| 导出物被误当成"自包含代码" | 用户拷到别的机器上跑不起来 | 产物头部与文档都写明"识别/输入在本机引擎执行"（§8.2 ⚠️）；skill 里显式引用本机引擎入口 |
| AI 转译引用不存在的部件 | 产物一跑就崩 | 导出前做**引用完整性校验**并拦截（DoD 明确要求） |
| 覆盖用户 Agent 里已有的工具 | 破坏别人的项目 | 差集复用 + 干跑预览 + 冲突检测，默认不覆盖 |
| WIDGETS 体积（base64 图） | 单文件过大 | 全局去重合并；体积上限与"外链"方案留待实测后再定 |
| 把"一句话生成"做成云端出坐标 | 越界（M0 已证不可用） | 只生成步骤骨架 + 语义描述，坐标一律运行时本地求 |

## 5. 验收口径（M4 DoD）

1. **导出产物可用**：导出到一个真实 Agent 目录（合成一个符合约定的目录当靶子 +
   人工检查），产物能被 Python 导入、`build_task(params)` 能产出可运行的脚本 JSON，
   并在案例库脚本上真跑一轮。
2. **引用完整性**：AI 转译产物引用的每个部件/工具都存在于产物中；缺引用必须在导出前被拦下
   （有测试钉住）。
3. **单向导出标注正确**：产物头部含来源脚本名与版本 + "修改脚本后请重新导出"，且**不做反向同步**。
