# 脚本构建器（Script Builder）

> 一个**面向所有人**的 Windows 桌面自动化脚本构建器：用户只需「截图目标、选择动作、增加条件、增加循环」四个操作，就能把重复的电脑操作做成一个可一键运行的脚本，全程不接触任何 RPA / 编程概念。

**它不做的事**（这是刻意的产品取舍）：不暴露"选择器""DOM""坐标链"这些概念；
界面文案只允许出现白话（见"术语对照"一节）。

---

## 能做什么

| 能力 | 说明 |
| --- | --- |
| **四个基本操作搭脚本** | 截图目标（先框页面、再框部件）→ 选动作 → 加条件 → 加循环 |
| **七个动作** | 点一下 / 点两下 / 输入文字 / 等一下 / 提示我 / 按快捷键 / 停止 |
| **判断与循环** | 如果看到 X / 如果没看到 X / 重复 N 次 / 一直重复直到看到 X / 一直重复 |
| **做完后应该看到 X** | 结果级校验：没看到就按你的设定重试、提示、停止或跳过 |
| **操作录制** | 你正常做一遍，它自动拆成"积木"（点一下 / 输入文字 / 等一下…），落成可编辑步骤 |
| **一句话生成** | 说一句"帮我做一个自动登录"，先搭好步骤骨架，位置由本机按文字找出来 |
| **导出给智能体** | 把脚本导出成 Agent 能直接调用的 Skill + Tools；也可让 AI 读截图转译成可读源码 |

## 快速开始（三步）

**前置**：Windows 10/11、Python 3.11+（勾选 Add to PATH）、Node.js 18+。

```bat
git clone https://github.com/jlj20240609/ScriptGenerator.git
cd ScriptGenerator
setup.cmd          :: 自动建 .venv、装引擎依赖、装 Electron 依赖，并自检
start-app.cmd      :: 启动应用（也可以双击它）
```

`setup.cmd` 做的事：建 `.venv` → `pip install -r requirements.txt` → `npm install`（在 `app/`）→
自检引擎能否导入。全部依赖都是**本地离线**能力，装完即可用，不需要联网也能跑脚本。

**第一次用建议这么试**：
点左栏「截图目标」→ 先框住要操作的窗口，再框住要点的按钮 → 选「点一下」→ 点「运行」。

## 云端 AI 是可选的

只有这四处会用到云端（智谱 `glm-4.6v`）：

1. 结果语义判定（判断"密码错 / 断网 / 验证码错"这类失败类型）
2. 运行自校准（界面改版后，AI 语义确认 + 模板自动重采集）
3. 导出的"代码脚本"转译（读截图生成可读源码）
4. 一句话生成脚本

开启方式：把 Key 写进 `.secrets/zhipu.env`（已被 git 忽略，不会进仓库）：

```
ZHIPU_API_KEY=你的key
```

**并且必须在界面弹窗里显式同意上传截图后才会联网**——不授权时全部功能照常可用，
只是上面四处会退化成"本地判不出来就交给人"。

### 一条不能越的边界

> **坐标一律由本机三级定位求出（UI 树 → 部件相似度 → 页面内坐标），云端 AI 只做语义判断与
> ±100px 的粗定位圈区，绝不作为运行时的坐标源。**

这条不是保守，是 M0 用数据换来的结论：纯 VLM 像素定位在同一批目标上跨模型命中率 0–50%、
漂移不可预测（详见 `docs/M0_进展记录.md`）。所以"一句话生成"也是**云端出意图（找哪块文字）→
本地出坐标**，两端各做自己可靠的那半。

## 目录结构

```
engine/          引擎（Python，独立进程，经 JSON-Lines IPC 与界面协作）
  capture.py     截图 / 窗口 / DPI / 权限(UAC) 判定
  locator.py     三级定位链
  matcher.py     OCR（RapidOCR）、模板匹配、ORB 特征
  executor.py    解释执行器（L1/L2/L3 + 失败策略）
  recorder*.py   操作录制（钩子 + 事件→积木 + 真机接线）
  exporter.py    §8 脚本 → Skill + Tools 导出
  agent_dir.py   目标 Agent 目录适配与自动写入
  ai*.py         云端 AI：语义判定 / 自校准 / 代码转译 / 一句话生成
  outcome.py     D3 结果语义判定（本地优先，判不出才问云端）
app/             Electron 界面（列表式编辑器 + 双截图选区 + 运行日志）
docs/            里程碑进展、验收数据、收口记录（M0–M4）
smoke/           冒烟脚本与诊断工具（真机验收、跑批、探针）
```

## 测试

用的是 Python 自带 `unittest`（不是 pytest）：

```bat
.venv\Scripts\python.exe -m unittest discover -s engine\tests -t .
```

界面自测（会真的启动应用并驱动界面按钮）：

```bat
cd app
node_modules\.bin\electron . --autotest-ui
```

## 已知限制（如实写在前面）

- **操作录制录不到中文输入法的组合结果**：钩子只看得到原始按键，会录成拼音字母。
  回放侧不受影响（走 Unicode 直发）。
- **UAC 弹窗（安全桌面）无法自动化**：Windows 的安全边界，任何 RPA 都绕不过；
  用「提示我」交给用户手动点即可。**目标程序若以管理员身份运行，本程序也必须以管理员身份运行**
  ——低权限进程不允许向高权限窗口发送点击/按键（UIPL 限制），程序会在框页面时明确提示这一点。
- **滚轮与单独的功能键**（Enter/Tab 方向键）只留痕、不生成动作——现有动作表里没有对应项，
  硬塞会做出一个假步骤。
- **一句话生成的位置靠文字匹配**：如果 AI 给的文字在页面上是**标签**（如"用户名"），
  位置会落在标签上而不是输入框，需要手动把那一步的目标改一下。
- 云端 AI 的判定准确率在自建合成用例集上为 92%（12 例），真实产品界面复杂得多，
  这是能力证明而非稳定性承诺。
- 目前的验收环境是 1920×1200 @125%，跨分辨率已验过 125%/150% 两档。

## 术语对照（对外只说白话）

| 界面上看到的 | 系统内部真实含义 |
| --- | --- |
| 截图目标 | 双截图：操作页面（窗口上下文 + 坐标系）+ 有效部件 |
| 积木 | 一个步骤节点（动作/条件/循环） |
| 做完后应该看到 X | 预期结果校验（结果级验证） |
| 提示我 | 暂停 + 人工介入 |
| 自动校准 | 首次执行/出错时 AI 看图确认目标并自动重采集 |
| 导出给智能体用 | 检测 Agent 目录 → 按约定拼装 Skill/Tools → 自动写入 |
