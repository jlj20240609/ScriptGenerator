# 「脚本构建器」引擎依赖（Windows）
#
# 安装（推荐用项目根目录的 setup.cmd 一键完成）：
#   py -3 -m venv .venv
#   .venv\Scripts\python.exe -m pip install -r requirements.txt
#
# 说明：
#   · 应用启动时会按顺序找 Python：环境变量 ENGINE_PYTHON → .venv\Scripts\python.exe
#     → smoke\.venv-ortcpu\Scripts\python.exe。所以虚拟环境放 .venv 即可被自动发现。
#   · 全部是**本地离线**能力：截图、OCR、模板/特征匹配、键鼠模拟。
#     云端 AI（智谱 glm-4.6v）是可选的，只有"结果语义判定 / 自校准 / 导出的代码转译 /
#     一句话生成"这几处会用到，且必须由用户显式授权后才会上传截图。
